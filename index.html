git init Cria um repositório Git na pasta atual.
git clone "URL" Baixa um repositório do GitHub.
git status Mostra o estado atual dos arquivos.
git add . Adiciona todas as alterações para o próximo commit.
git commit -m "mensagem" Salva as alterações no histórico do Git.
git push Envia os commits para o GitHub.
git pull Baixa as alterações do GitHub.
git log Mostra o histórico de commits.
git branch Mostra as branches existentes.
git checkout -b nome Cria e entra em uma nova branch.
git checkout main Volta para a branch principal.
git merge nome Junta uma branch com a branch atual.
git remote -v Mostra o repositório remoto conectado.
